# AI Services

Reusable AI helpers for speech, prompt engineering, validation, and text-to-speech.

## Modules

- `speech/` - speech-to-text adapters.
- `llm/` - prompt builders and language model clients.
- `prompts/` - reusable system prompts and field prompts.
- `tts/` - text-to-speech helpers.
- `utils/` - validation and response formatting helpers.
